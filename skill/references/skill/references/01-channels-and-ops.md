# 01 · 渠道、环境与操作风控

## 渠道与登录（权限归用户）

| 渠道 | 适合 | IM 入口 | 备注 |
|---|---|---|---|
| BOSS直聘 | 中小公司、直招老板、回复快 | `zhipin.com/web/geek/chat` | 反爬最严；**不要直接改地址栏访问职位页**，会触发 `_security_check` 并吞掉同窗口其它标签 |
| 猎聘 | 中高端、猎头岗、薪资透明 | `liepin.com` 站内「我的沟通」浮窗 | 猎头集中在 **9–11 点、17–19 点** 处理消息，其余多为未读 |
| 智联招聘 | 大企业、外企、传统行业 | `i.zhaopin.com/im` | 在**同一无痕窗口**新开标签即沿用登录态 |
| 51job / 本地人才网 | 补充来源 | — | 按地域筛选 |

**开场六步**：打开全部渠道 → 用户勾选要用哪些 → 用户自己完成登录（不代填密码、不代扫码）→ 逐渠道截图确认 → 只推进"已登录"的渠道 → 未登录的挂起并告知。

## 检索路径（三条都走）

1. **搜索页**：关键词 + 城市（猎聘要先点「全国」→ 城市弹窗 → 输城市名 → 选结果，**猜 URL 参数无效**）
2. **首页推荐流**：往往比搜索结果质量更高（高薪、学历放宽的岗常出现在这里）
3. **猜你喜欢**：岗位详情页底部的相似推荐，常有同公司不同岗

## 操作风控（拟人）

| 参数 | 建议值 |
|---|---|
| 轮次间隔 | 手上事情全做完后 **60–120 分钟随机**（固定周期也是机器人特征）；有活跃对话时按对话节奏走 |
| **单轮打招呼量** | **≥5 家、≤100 家**（零回复时必须补量；少于 5 等于没推，多于 100 变群发）|
| 单页连续点击 | ≥6 次必须停顿 2–3 秒 |
| 打开 JD 后停顿 | 2–4 秒 |
| 同一会话每日查看 | ≤2 次 |
| 触发验证码/风控 | **立即停下**，截图说明，请用户处理；不反复重试 |

## 坐标与窗口（Windows 桌面自动化必读）

- 截图换算：`screen_x = 窗口原点x + 图内px / imageScale`；每次截图后重算，窗口位置/缩放会变
- **动手前先 `activate_window` 目标窗口**，再点击、再粘贴；两个浏览器窗口重叠时尤其要确认焦点，否则文字会粘到另一个窗口
- BOSS 的「职位」导航有时点了不跳转 → 改用「查看职位」链接进入职位页，或转用别的渠道刷岗
- 消息列表**随新消息重排**：点之前截图确认行坐标，点之后确认头部姓名是目标
- 页面短暂空白（"30 天内暂无联系人"）→ **先 F5**，不要重复操作
- 用户在使用电脑时 `activate_window` 会返回 **foreground lock** → 立即停止输入类操作，只做后台截图读取与起草
- 图片/视频上传会弹系统文件对话框（`#32770`）→ `list_windows` 定位后再操作
- 文件扩展名与实际格式不符时（读图报错）→ 读文件头 magic bytes，**生成修正副本**再用，别删原文件

## 安全底线

- 聊天里**绝不写联系方式**（手机号/微信/邮箱/二维码/外链）：平台会打码并警告，多次违规封号
- 要换联系方式：只用「换微信」「换电话」按钮；对方索要时答"平台规则不允许直接发，您点一下交换微信"
- 不代用户做身份认证、人脸、扫码；不索要密码
