# 04 · 交付物（六份，缺一不可）

## 1. 候选人档案（`候选人档案.md`）
见 `00-intake.md` 末尾模板。含基本信息、卖点卡、意向、披露边界、投递台账、待补充。
**它是唯一事实源**：所有话术、简历、面试包都从这里取数。

## 2. 卖点卡（写进档案第二节）
- **保留原稿数据，不改口径**：同一组数字在任何场合不换算、不混写
- 结构：经验年限 / 团队规模 / 峰值战绩 / 投放规模 / 效率指标 / 擅长类目
- 附加「口径纪律」条款：禁止出现两种版本（如"5000 万"与"5164 万"混用）

## 3. 案例库索引（`案例库索引.md`）
| 类目 | 文件 | 什么时候发 |
|---|---|---|
| 服饰/鞋服、护肤美妆、茶、奢侈、达人代投、商品卡、食品大健康、数据截图、综合文档、视频 | 具体文件名 | 按对方类目精准匹配 |

**发放原则**
1. 对方明确要案例再发，不主动轰炸
2. 按类目精准匹配，别发错
3. 优先发 1–2 张最能打的，要更多再追加
4. 收入流水只在正式谈薪或对方明确索要时发
5. 发之前记账（发给谁、发了哪几个文件）

**加分做法**：把文件名看不懂的图打开辨认，标注"实际内容 + 什么场合发"，形成「⭐ 王牌截图」表。
（示例：单店月销 486 万的全域结构图、千川月度总账、目标 vs 完成日追踪表、办公室实拍大屏、高客单礼盒场）

## 4. 投递台账（写进档案第五节 + 日志）
| # | 公司 | 岗位 | 薪资 | 状态 | 备注 |
状态：🟢活跃 / 🟡已读不回 / ⚪未读 / 🔵冷 / ✅已面试 / 🎯已 Offer
**台账要能回答三个问题**：这家聊过吗？聊到哪一步？为什么放弃？

## 5. 面试包（`面试包-公司名.md`）
九部分：公司摸底表、岗位拆解、30 秒自我介绍、必答题、反问清单、争取更高岗的谈法、案例准备表、劳动法核查 6 问、面试前 24 小时清单。

**打法方案（独立一份，更关键）**：**讲方案，不讲履历**
> 行业本质一句话 → 3–4 个真实痛点 → 30/60/90 天打法 → 具体编制表 → 考核口径 → 合规红线 → 反问 → 收尾要三个数

**一页纸版**：把上面压成一屏，面试前五分钟扫一眼。

## 6. 日报（`日报-YYYY-MM-DD.md`）
- 一句话结论
- 动作量（触达/回复/达标）
- 已定面试、活跃线索、待回名单
- 婉拒清单（附依据）
- 淘汰岗位与主因
- 今天踩的坑与修复
- 明天第一件事（按优先级）
- **需要候选人确认的事项**

## 日志规范（`求职决策日志.md`）

每轮追加一节：

```markdown
## N. HH:MM — 一句话结论
### 扫描（各渠道：有无新回复）
### 动作（发了什么、回了什么、为什么这么回）
### 判断（为什么推/不推/婉拒，依据要能复查）
### 状态（🟢/🟡/⚪/🔵 变化）
### 下一步（下一轮优先级）
```

**要点**：写"为什么"，不写"做了什么"的流水账；婉拒必须留依据（对方说了什么），便于复盘与避免重复。

## 闭环：尽调 → 推荐 → 面试 → Offer → 入职

| 阶段 | 交付 |
|---|---|
| 尽调 | 五维 + 背调 + 红线 → 推荐理由 3–5 条带数字 |
| 推荐 | 岗位卡（岗位/薪资结构/公司背景/理由/风险）→ 候选人决定投不投 |
| 投递 | 定制话术 + 按需发简历/案例 → 记时间与渠道 |
| 面试 | 约时间 → 面试包 + 打法方案 → 时间地点同步候选人 |
| Offer | 核底薪/提成算法/社保基数/试用期/发薪日/违约金 → **拿不到书面 Offer 不催入职** |
| 入职 | 备材料、确认到岗日 |

**反馈机制（防重复）**：每推进一个节点都要向候选人要一次反馈；他不主动反馈时，**下次对话提醒**，并说清哪些企业/岗位已聊过，避免重复对话同一家同一岗。
