# 00 · 开工前：候选人接洽与简历优化

> 顺序不可颠倒：**1.1 素材 → 1.2 意向 → 1.3 迷茫引导（条件触发）→ 1.4 优化包装 → 1.5 一岗一版**。
> 跳过任何一步，后面的筛选与话术都会跑偏。

## 1.1 索取素材

- 现有简历（PDF / Word / 文本均可），并**确认可对外使用的经历与数据范围**
- 作品 / 案例 / 业绩流水的**存放路径与原稿**（如 `D:\...\案例库索引.md`）
- 没有简历：先协助从零整理基础版（基本信息、工作经历、项目成果、技能），**不进入推荐环节**

通读两遍，产出「简历诊断」：
- 优点：哪几段能打动 HR（有数字、有 0-1、有团队规模）
- 缺点：无量化、时间断档、职责写成岗位说明书、类目与目标岗不匹配
- 风险：履历口径矛盾、学历与 JD 不符、跳槽频率、**离职时间是否写准**

## 1.2 问清目标岗位与公司（逐项写进档案）

| 维度 | 要问的 |
|---|---|
| 岗位 | 名称、职能方向、管理 or 执行、行业赛道 |
| 公司 | 行业、规模、性质（品牌方/MCN/产业带/上市）、**偏好名单、排除名单** |
| 硬性条件 | 城市、**底薪底线**、提成预期、到岗时间、是否接受出差/异地 |
| 其他 | 现雇主、**竞业限制**、离职原因、**可对外披露的信息范围** |

## 1.3 迷茫时的专业引导（条件触发）

说不清方向时，用猎头视角引导，**不替其决定**：
1. 复盘简历：可迁移技能、行业积累、可量化成果
2. 对照市场：本地在招岗位、薪资区间、成长路径
3. 给 2–3 个方向，每个方向三句话：**为什么适合（引用简历证据）／薪资与前景／主要风险**
4. 候选人确认或修正后，再进下一步

## 1.4 优化与包装（真实不虚构）

| 动作 | 做法 | 红线 |
|---|---|---|
| 结构重组 | 按 JD 调模块顺序，最相关前置 | 不改事实顺序 |
| 数据化 | "负责直播运营" → "操盘 6 个直播间，单月 GMV 峰值 5164 万" | 数字须可核验 |
| 关键词对齐 | 按 JD 补关键词（千川/罗盘/达人矩阵） | 只写做过的 |
| 成果量化 | 用增长率、占比、效率表达 | 不编 ROI/GMV/团队规模 |
| 排版 | 1–2 页、模块清晰、倒序 | 不伪造学历/证书/任职 |

> **原则：包装是表达的优化，不是事实的改写。** 未经确认的数据不用；无法核实的标「待核实」。

## 1.5 一岗一版

- 文件名：`简历-岗位-公司.md`（如 `简历-直播运营经理-某品牌.md`）
- 定制项：摘要对齐 JD、项目前置、技能关键词、**案例按类目匹配**
- 交付前经候选人确认；确认后为**唯一对外版本**，未授权不得改数据
- 归档：`候选人 / 岗位 / 版本 / 日期`
