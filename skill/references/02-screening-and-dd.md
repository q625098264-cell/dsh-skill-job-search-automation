# 02 · 岗位筛选与人岗匹配（推荐前尽调）

## 五维匹配

| 维度 | 判据 |
|---|---|
| ① 类目契合度 | 同类目 ✅；邻近类目（个护↔美妆、食品↔生鲜）可谈；完全跨行降级 |
| ② 职责重合度 | **≥70% 才推荐**；50–70% 可试但要先问清；<50% 不推 |
| ③ 薪资结构真实性 | 发布薪资 vs 岗位层级 vs 公司体量，三者匹配才可信；小公司开高薪多为虚高，必须问穿底薪 |
| ④ 城市与办公安排 | 目标城市优先；外地不投；长期驻场降级 |
| ⑤ 企业经营稳定性 | 见下方两级背调判级 |

## 红线（触发即不推荐，并**主动告知候选人原因**）

- 收费 / 押金 / 强制入股 / 以"合伙"名义让候选人出钱
- 岗位职责含糊（只写"面议"、说不清做什么、与标题明显不符）
- 薪资明显虚高，或一聊就变"底薪 8K + 提成"
- 纯提成无底薪 / 日补贴 + 礼物提成（公会、保险式）

## 直接排除的类型

| 类型 | 判据 |
|---|---|
| 主播/中控/场控 | 标题写运营，JD 是出镜/盯盘/排班 |
| 招商/销售 | JD 是拉商家、卖课、招加盟 |
| 外地岗 | 非目标城市 |
| 层级错配 | 标题"负责人"，JD 实为事业部总经理（战略/组织/对外关系）|
| 门店零售运营 | 做的是门店陈列、店长管理，不是线上运营 |
| **平台错配** | JD 出现「直通车/钻展/万相台/引力魔方/天猫小二/聚划算」= 淘天岗；出现「千川/随心推/巨量/抖店/商品卡/达人分销」= 抖音岗。**平台不符，薪资再高也不要投**，专业面必挂 |
| **学历硬卡** | 明写"统招本科及以上"，候选人非统招则跳过（或先坦诚问能否放宽）|

> 反例提醒：**成立时间不作为排除条件**。新公司也可能有好岗位，只看主体类型、注册资本与 JD 匹配度。

## 输出规范：推荐理由 3–5 条，每条带数字

格式：`岗位要求 → 候选人的对应（数字）`，口径与卖点卡完全一致。

> 示例：
> 1）要求"操盘过年 GMV≥XXXX 万" → 该类目月 GMV XXXX 万（年化 X 亿+）
> 2）要求"千川投放" → 月耗最高 XXX 万、日耗峰值 XX 万
> 3）要求"团队搭建" → 带过 XX 人、培养 XX 名核心骨干

## 公司背调（两步，不可跳）

### 第一步：平台内工商信息（BOSS「工商信息」/ 猎聘「公司信息」右栏）

| 记录 | 判级 |
|---|---|
| 公司全称带"店/商行/经营部"、个体工商户、个人独资 | 🔴 不推 |
| 有限责任公司但注册资本 <100 万 或 规模 <50 人 | 🟡 需问穿 |
| 有限公司及以上、注册资本 ≥100 万、规模 50+ | 🟢 可推 |
| 已上市/知名品牌 | 🟢 直接通过 |

> 成立日期仅作参考，**不单独排除**。

### 第二步：外部四项（有联网检索能力时）

1. **医社保与纳税**：参保人数、纳税信用等级、欠税公告
2. **官司纠纷**：劳动争议、被执行、失信、限高
3. **社交口碑**：小红书/脉脉/知乎搜"公司名 + 欠薪/裁员/加班"
4. **搜索黑料**：百度"公司名 + 骗/欠薪/仲裁"

> 无联网检索能力时**如实说明"外部尽调未做"**，不要假装做过。

### 🟡 级必问穿的三件事

1. 劳动合同签在**哪个主体**
2. 社保公积金**按什么基数**缴
3. 发薪日、试用期、提成发放条件（离职后发不发）
